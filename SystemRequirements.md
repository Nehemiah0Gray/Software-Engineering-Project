# Customer Statement of Requirements

This website (no name) is a tool that helps users interested in building computers or buying tech items find better deals during periods of inflated prices. This website allows users to find the latest deals, compare prices, and analyze price trends to determine what, when, and where they would like to make a purchase. The goal is to help people who may not have enough money to spend on tech find affordable ways to break in and get into tech. Users would be able to view these deals as soon as they visit the website, find a deal, see the best price, and make purchases quickly. For further development, mainly for those wanting to build a computer, a system to simulate and gather correct parts for a system to provide more clarity on purchases.

# Requirements Specification

Functional:

1.  User Log System

    a.  Users can create an account

    b.  Registered Accounts can log in and log out

    c.  Users can reset passwords

    d.  Users can update their user information

2.  Wishlist/Saved Products

    a.  Users can add and remove items to a list

3.  Product Data Collection

    a.  Collects product information (price, original price, image, description, retailer, URL)

    b.  Identifies if products are in stock or unavailable

4.  Searching Function

    a.  Allow users to search for tech products through their name or keywords

    b.  Provides relevant results when users enter parts of the product names/keywords

5.  Filtering/Sorting

    a.  Allows users to sort by certain categories (such as prices) and sort them ascending or descending)

    b.  Filter by different categories (such as what company produces them, the amount of what it holds, etc.)

6.  Display of Deals

    a.  Upon entering the website, the system would display the current deals on different websites

    b.  .Displays deals, percentage, original and deal price, the amount calculation change, retailer, image of product, availability, and name.

7.  Price History

    a.  Stores the price history of all products

    b.  A location to check the price history of products on display

    c.  Shows significant price drops with sufficient available historical data

8.  Retailer Information

    a.  Identify what retailers offer these deals

    b.  Provides a URL to access the deal of the products page

    c.  System shall keep retailer information in its database

    d.  Allows additional support to new retailers in the future

Non-Functional:

1.  Performance

    a.  The system should display everything as soon as possible once the website is opened.

    b.  Search displays should be shown seconds after the search has been queried

2.  Scalability

    a.  The system shall be designed so that changes such as price updates, additional retailers, and new products can be added without major changes to the system as a whole.

3.  Availability

    a.  Website should be up 24/7 without errors, with connections from any users

4.  Reliability

    a.  Provides accurate, uncorrupted data of all products and retailing available to all users

5.  Security

    a.  User passwords are stored in a hash, authentication is used to reduce botting, and usage of a general safe website production practices would be observed in the website\'s production.

6.  Usability

    a.  The website should be clear and distinct, with all main functions

    b.  Any secondary or tertiary functions should have the ability to explain what users need to know how to use these functions

    c.  Navigation, search, sorting, etc., should be easy to understand

7.  Compatibility

    a.  The website shall function on commonly used modern browsers such as Chrome, Firefox, Edge, and Safari.

    b.  The website should support current desktop and mobile operating systems.

8.  Data Privacy

    a.  The system shall collect only the user information necessary to provide its services.

    b.  User information shall be stored securely.

    c.  The system shall provide users with information about how their data is collected and used.

    d.  Users should be able to request deletion of their account and associated personal information where applicable.

9.  Legal and Retailer Compliance

    a.  The system shall collect and display retailer information in accordance with applicable retailer terms and conditions.

    b.  All information from retailers would be obtained in accordance with their legal terms and availability.

10. Backup and Recovery

    a.  The system shall regularly back up important databases and configuration information.

    b.  The system shall have a recovery process for restoring product and user data after a system failure.

    c.  Backups shall be protected from unauthorized access.
